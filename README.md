# ثروات التقنية | Tharawat Technology

Official company website for **Tharawat Technology** — built with Angular 19.

## Features

- Arabic-first RTL layout
- Brand identity (Gojali fonts + logos)
- Company profile, services, partners, and contact
- Responsive design

## Requirements

- Node.js 18+ (recommended 20+)
- npm 9+

## Setup

```bash
npm install
npm start
```

Open [http://localhost:4200](http://localhost:4200).

## Build for production

```bash
npm run build
```

Output: `dist/tharawat-website/browser`

## Project structure

```
src/app/
  components/   # Header, hero, about, services, partners, contact, footer
  data/         # Site content
public/assets/  # Logos, fonts, hero images
```
